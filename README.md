# NftDepth

NftDepth is a decentralized, autonomous platform that enables real-time, auto-scaling data processing for large-scale NFT market analytics.

NftDepth is built to be simple and practical, focusing on doing one thing well.

**Why NftDepth?**

- NftDepth is a decentralized, autonomous
- platform that enables real-time, auto-scaling
- data processing for large-scale NFT

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/NftDepth.git`
2. `cd NftDepth`
3. Install in editable mode: `pip install -e .`

## Configuration

NftDepth is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
